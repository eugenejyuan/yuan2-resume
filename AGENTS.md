# AGENTS.md

`yuan2resume` is a **typographic grammar**, not a fill-in-the-blank template.

Seven primitives compose freely, and the alignment holds as long as you do not bypass
them. `main.tex` is a **skeleton**, not the required shape of a resume — invent the
sections the person actually needs. `examples/` holds two skeletons that share no
section list; that is the point. Every identity in them is a bracketed placeholder --
they demonstrate structure, and assert nothing about anyone.

Read `docs/GRAMMAR.md` before writing content. It defines the primitives and the six
invariants that keep the layout aligned.

## Files

| Path | Role |
|---|---|
| `main.tex` | The only file you normally edit: class options, identity, content. |
| `examples/*.tex` | Two placeholder skeletons. Read for shape; do not edit as a deliverable. `academic.tex` is also the source of the README image. |
| `yuan2resume.cls` | The grammar itself. Never edit it to fix a content problem. |
| `configs/fonts-*.tex` | Font sets, selected by the `fontset` class option. |
| `fonts/download.sh` | Downloads and verifies the configured commercial fonts. |
| `docs/GRAMMAR.md` | Primitives, invariants, tuning knobs. Read first. |
| `docs/DESIGN.md` | Why the invariants hold, with measurements. Read before changing the class. |
| `docs/FONTS.md` | The four font slots; installing or adding a set. |
| `assets/*.png` | Generated by `make preview`. Never hand-edit or hand-replace. |
| `scripts/check.sh` | The definition of done below, executable. |
| `scripts/test.sh` | Positive and negative contract tests for class changes. |

## Commands

Requires **XeLaTeX** (TeX Live / MacTeX). The class rejects other engines immediately;
the one-time `make fonts` setup also requires `curl`.

```bash
make          # build main.tex into build/
make check    # run the definition of done; non-zero exit if not shippable
make test     # run class contract tests, including expected failures
make examples # build and check every examples/*.tex (page budget 2)
make fonts    # download and verify the commercial fonts from the original template
make png      # render every page to build/page-N.png
make preview  # regenerate the README image from examples/academic.tex

PAGES=2 scripts/check.sh main.tex       # raise the page budget for a CV
```

`make check` is the definition of done, executable. Run it; do not re-derive it by
hand. After the fonts are installed, it needs nothing but `latexmk` — the page count
is read out of the log.

## Workflow

1. Run `make fonts` once after cloning.
2. Edit `main.tex`. Compose sections from the primitives.
3. Build.
4. `make check`. A clean compile does not mean a correct layout: overfull boxes are
   warnings, not errors, and the PDF is still produced.
5. **`make png` and look at it.** The one thing no script checks is whether the page
   reads well.
6. Iterate on content until `make check` passes. Fix overflow by rewriting the prose
   shorter, never by nudging spacing.

## Definition of done

`make check` must exit zero. It enforces: the document builds; no `Overfull \hbox`;
no `Font file not found`; no `Class yuan2resume Error`; page count within budget; no
`\vspace` in content; no placeholder text left. A `Class yuan2resume Error` means the
composition is wrong, not that the message needs working around.

Two things it cannot check — you still owe these:

- **Look at the rendered page.** `make png`. Every right-hand value of `\cvpair`
  (dates, locations) must sit flush against the right margin, and every section
  heading in the left rail.
- A page less than one third full is a defect, and no script can tell you that.

## Never

- Never hand-align with `\hfill`, `\hspace*{\fill}`, or a raw `tabular`. Use `\cvpair`.
- Never write `\vspace` in content at all — not even `\vspace{\cventrysep}`. Use
  `\cvgap` (or `\cvgap[2]`), which merges rather than stacks and cannot express an
  absolute length. To change how big the gap is, set `\cventrysep` in the preamble.
- Never use `\section`, `\subsection`, `itemize`, or `enumerate`.
  Use `cvsection`, `cvitemize`, `cvnumlist`.
- Never use `\name`, `\position`, `\phone`, `\email`, `\homepage`. They are unsupported.
  Use `\cvname`, `\cvposition`, `\cvcontact`, `\cvemail`, `\cvlink` — and
  reach for `\cvlink` for GitHub / ORCID / LinkedIn rather than asking for a new
  command; the contact block is an open-ended ordered stack.
- Never name a glyph in content. Ask for a slot (`\cvIconScholar`, `\cvIconGitHub`).
  Every item must be inside a `\cvcontactrow`; order is declaration order.
- Never fix an overfull header by shrinking `\cvheadsep` or `\cvcontactsep`. The header
  sizes itself; an overfull means a label is too long. Shorten it.
- Never indent a nested block with `\hspace`, `\leftskip`, or a `minipage`. Use
  `cventry`, which indents from the left only and so preserves the shared right edge.
- Never use `\newpage`, floats (`figure`, `table`), or footnotes inside `cvtwocolumn`.
  `paracol` does not support them.
- Never uppercase or `\textsc{}` a section heading. `cvsection` already applies small
  caps; doing it twice breaks the cap height.
- Never edit `yuan2resume.cls` or `configs/` to accommodate content. If content will
  not fit the grammar, rewrite the content.
- Never hand-make or hand-edit the README image. It is a render of
  `examples/academic.tex`; run `make preview`. An image showing content that no file
  in the repository contains is how the old one came to assert a fabricated CV.

## Escaping

Resume text hits these constantly: escape `& % $ # _ { }`.
Write `R\&D`, `95\%`, `C\#`, `Ph.D.\ Candidate`.
Use `--` for date ranges (`2020 -- 2024`) and `` ``quoted'' `` for quotation marks.
Long URLs belong in `\href{url}{short label}`, not as bare text that overflows.

## Font sets

Four semantic slots (`main`, `\TitleFont`, `\SectionFont`, `\CodeFont`), one shipped
configuration (`fontset=commercial`). Its font binaries are ignored by Git; run
`make fonts` to download and verify the files used by the original template. The
configuration loader remains open-ended, so local sets can still be added as
`configs/fonts-<name>.tex`. A missing required file fails immediately with
`Font file not found`. Details: `docs/FONTS.md`.
